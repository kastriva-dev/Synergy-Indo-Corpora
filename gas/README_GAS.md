# Legacy GAS archive — Sinergi Global

Folder ini dipertahankan sebagai source/reference historis dari implementasi Google Apps Script, Sheets dan Drive sebelumnya. Runtime website saat ini tidak memanggil deployment GAS tersebut.

Jangan deploy ulang script ini atau menghubungkan kembali environment GAS untuk arsitektur Firebase, kecuali perusahaan secara eksplisit menyetujui rencana rollback. Jika spreadsheet lama berisi konten CMS publik, ekspor dan tinjau konten tersebut, lalu impor ke koleksi Firestore yang dijelaskan di docs/FIREBASE_SETUP.md.

Jangan menyalin data kandidat/CV asli dalam migrasi awal sebelum perusahaan menyetujui kepemilikan data, pemberitahuan privasi, masa retensi, akses serta kebijakan penghapusan. Source historis ini tidak boleh dianggap sebagai backend yang aktif.
